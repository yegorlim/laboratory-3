## Висновок
У ході виконання лабораторної роботи №3 я набув практичних навичок роботи з командною оболонкою Bash. Зокрема, було освоєно навігацію по файловій системі за допомогою команд `cd`, `pushd` та `popd`, роботу з прихованими системними каталогами (`.git`), перегляд та редагування файлів у консольному редакторі `nano`. Також було налаштовано власні псевдоніми команд (alias) для оптимізації роботи та відпрацьовано базові прийоми обробки тексту за допомогою команд `echo`, `cat` та фільтрації через `grep`.
